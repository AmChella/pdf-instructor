🔍 PDF Instructor

Interactive PDF analysis tool

Features:

  • 🖼️ Image detection and highlighting
  • 📊 Table detection and analysis
  • 📝 Interactive text selection
  • 📍 Coordinate submission
  • 📏 Line spacing analysis

Instructions:

  1. Select a PDF file
  2. Optionally add JSON geometry data
  3. Click "Open PDF Viewer" to start

Shortcuts:
Ctrl+Shift+D: PDF diagnostics
Ctrl+Shift+T: Overlay test
